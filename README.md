# TrustBOM Documentation

Documentation for [TrustBOM](https://github.com/tuberlin-blockchain-prototyping/sharing-sbom-system)

## Local Development

```bash
npm install
npm start
```

This starts a local development server at http://localhost:3000.

## Build

```bash
npm run build
```

## Deployment

This site is automatically deployed to GitHub Pages via GitHub Actions on push to `main`.

View the live documentation at: https://tuberlin-blockchain-prototyping.github.io/trustbom-docs/docs/
